# 小红书封面设计提示词

封面设计只走这份提示词，不调用检测脚本，也不要发明封面接口。用户没给标题时，先用 `intake.md` 的「仅封面」模板提问。

默认交付 3 套方案和可复制的生图提示词。用户没有明确说「出图」时，到方案为止。用户指定某一套并要求出图，且当前环境有生图工具时，再用该套的英文提示词出一张预览，并说明中文标题需要后期叠。

## 尺寸和安全区

小红书首图用竖版 3:4。

| 用途 | 尺寸 | 说明 |
| --- | --- | --- |
| 笔记首图，默认 | 1242×1660 px，3:4 | 信息流里更占屏。也兼容 1080×1440 |
| 方封面，仅用户明确要求 | 1080×1080 px，1:1 | 不要当成默认 |

安全区：

- 四边各留约 8% 不放关键信息
- 核心卖点和人脸放在中上部
- 底部约 15% 少放必须被读到的字，避免和笔记标题抢空间
- 封面大字控制在 4–12 个汉字，最多两行
- 小字不超过 3 行。小红书封面靠一眼读懂，不靠段落

## 先定类型

按用户风格选主方案，另外两套用固定角色补齐，保证每次都有对比。

| 风格 | 画面 | 文字 |
| --- | --- | --- |
| 大字报 | 纯色、渐变或轻微纹理，中央大留白 | 4–12 字，高对比 |
| 前后对比 | 同一主体左右或上下两种状态 | 每侧不超过 6 个字 |
| 清单干货 | 纸感、白板或浅色卡片，留出 3 行文字区 | 3 个要点，不要超过 5 行 |
| 真人出镜 | 自然光、半身或特写，脸在上三分之一 | 大字放在侧边或下方留白，不挡脸 |
| 产品特写 | 桌面静物、浅景深，主体居中 | 角标短句 |
| 你来定 | 按赛道选下面的默认风格 | 说明为什么选它 |

赛道默认，用户没指定风格时用：

| 赛道 | 默认风格 | 主色 |
| --- | --- | --- |
| 美妆 | 产品特写 | 奶油白 + 豆沙粉 |
| 穿搭 | 真人出镜 | 黑白或低饱和 |
| 美食 | 产品特写 | 暖黄 + 食物本色 |
| 家居 | 大字报 | 原木色 + 米白 |
| 母婴 | 大字报 | 浅杏 + 雾蓝 |
| 教育 | 清单干货 | 深蓝 + 白 |
| 本地生活 | 前后对比或场景特写 | 实景色，少加滤镜 |
| 其他 | 大字报 | 墨蓝 + 米白 |

## 封面大字

用户给了 4–12 个字就用，只在踩中下面的禁区时改写，并说明改了什么。用户写「帮我写」时，从标题里抽结果或对象，不要把整句标题搬上封面。

封面和提示词里不要出现：

- 绝对化：最、第一、顶级、国家级、100%、永久、根治、保证
- 收益和疗效承诺：必瘦、包过、稳赚、日入、治愈
- 引流：加微信、私信领、看主页、扣 1
- 恐吓式标题：不看就亏、再不用就晚了

这次如果先做了笔记检测，封面大字还要避开报告里点名的敏感词和资质风险表述。找不到安全的短句时，改成中性说法并告诉用户。

## 三套方案怎么配

1. 方案 A，点击向：大字报。即使用户选了别的风格，也给这一套作对照。
2. 方案 B，信任向：清单干货或前后对比。教育、测评、教程优先清单；变化类内容优先对比。
3. 方案 C，指定风格：按用户选的风格。用户选了「你来定」或没选，方案 C 用赛道默认，并写一句选择理由。

三套的封面大字可以不同，但都要对应同一个卖点，不要做成三篇不同的笔记。

## 每套都按这个格式输出

```
【方案】：A / B / C
【封面主题】：
【封面类型】：
【尺寸】：1242×1660（3:4）
【主色】：
【封面大字】：
【副文案】：没有就写「无」
【布局】：
【安全区】：关键信息放在哪，哪里留空
【点击理由】：一句话，只说信息是否一眼能懂，不预测流量
【敏感词自检】：列出避开了什么；没有风险就写「未使用绝对化、疗效承诺和引流话术」
【后期叠字】：字体气质、字号层级、字的位置、要不要描边
【中文生图提示词】：
【英文生图提示词】：
```

生图提示词固定要求：

- 画面中不要文字、字母、水印、logo、UI
- 英文提示词末尾带 `no text, no letters, no watermark, no logo, empty space for a title overlay, vertical 3:4`
- 中文提示词写明「不要任何文字，留出标题叠字区，竖版 3:4」
- 提示词描写光线、主体、配色和留白，不把封面大字写进画面
- 人物出镜只写「一位成年人」，不指定真人明星，不要求过度磨皮

## 交付完之后

用三行收束，不要再展开：

- 更适合信息流停住的是哪一套
- 封面大字最终用哪一句
- 若要出图，请用户回复方案字母

不要承诺这套封面会涨曝光、过审或不被限流。
