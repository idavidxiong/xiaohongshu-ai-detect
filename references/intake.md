# 初始化提问模板

信息不够时，从下面四版里选一版原样发送。不要改写，不要一次发多版，不要在提问前调用检测脚本或先出封面。

已经提供的字段从模板里删掉，只留缺口。用户明确说「介绍一下」时，不要用本文件，改读 `product.md`。

## 何时用哪一版

| 情况 | 用哪一版 |
| --- | --- |
| 没说要检测还是做封面，或只说「帮我看看」「开始」 | 完整版 |
| 明确要检测，但没有笔记正文 | 仅检测 |
| 明确要封面，但没有笔记标题 | 仅封面 |
| 检测和封面都要，标题或正文缺一项 | 检测加封面 |

标题和正文都有，而且意图明确时，不要提问，直接做。

## 完整版

```
要用小红书封面和AI检测工具的话，先选这次要做的事（可多选）：

1. 小红书敏感词检测
2. 资质检测
3. AI率检测
4. 内容质量检查
5. 小红书封面设计

检测请直接贴：
- 笔记标题：
- 赛道（美妆 / 穿搭 / 美食 / 家居 / 母婴 / 教育 / 本地生活 / 其他）：
- 正文（含话题标签）：

封面请补充（做封面才填）：
- 一句话卖点：
- 封面风格（大字报 / 前后对比 / 清单干货 / 真人出镜 / 产品特写 / 你来定）：
- 封面大字（4–12 个字，没有就写「帮我写」）：
- 主色（没有就写「无」）：

贴全之后我就开始。只想了解工具能做什么，直接说「介绍一下」。
```

## 仅检测

```
做小红书笔记检测（敏感词、资质、AI率、内容质量），请贴这 3 项：

- 笔记标题：
- 赛道（美妆 / 穿搭 / 美食 / 家居 / 母婴 / 教育 / 本地生活 / 其他）：
- 正文（含话题标签）：

正文超过大约 500 字时，内容质量、敏感词和资质会一并展开。更短时，分段 AI 率仍然会出，内容质量报告可能不展开。
```

## 仅封面

```
做小红书封面，请发这 5 项：

- 笔记标题：
- 一句话卖点：
- 赛道（美妆 / 穿搭 / 美食 / 家居 / 母婴 / 教育 / 本地生活 / 其他）：
- 封面风格（大字报 / 前后对比 / 清单干货 / 真人出镜 / 产品特写 / 你来定）：
- 封面大字（4–12 个字，或写「帮我写」）：

有主色也可以一并给我。没有的话我按赛道选一套。默认出 3 套 3:4 封面方案和生图提示词，画面不写字，标题后期叠。
```

## 检测加封面

```
笔记检测和封面一起做。还差这些，补上我就开始：

- 笔记标题：
- 正文（含话题标签）：
- 赛道：
- 一句话卖点：
- 封面风格（大字报 / 前后对比 / 清单干货 / 真人出镜 / 产品特写 / 你来定）：
- 封面大字（4–12 个字，或写「帮我写」）：

我会先出敏感词、资质、AI率和内容质量，再出封面。封面大字会避开检测里点出的敏感词。
```
